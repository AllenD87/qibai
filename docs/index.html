会聊天

一个有状态的桌宠

5 个角色各有形象、性格、亲密度与音色；表情与动作由模型的结构化输出驱动；久坐、喝水、护眼会主动冒出来提醒你。

听得懂

语音真的在本机跑

本地 whisper 转写，音频不出本机；喊一句「小小」进免提，VAD 自动断句；支持双工打断，它说话时你能插话。

真动手

能替你把活干完

14 个内置技能：建工程、读写文件、跑测试、查代码、搜网页、开应用；危险操作逐次确认，不确认就不执行。

记得住

上下文不爆，任务能续上

四层上下文 + token 预算 + 自动压缩 + 快照；长任务先出计划、可暂停可恢复、按依赖图并行、跑歪了能从某一步重跑。

能扩展

能力从外面长进来

技能包 zip 导入即装、专家插件换人设和工具白名单、标准 stdio MCP、以及控制台里一条配置就能加的自定义连接器。

守边界

默认关，越界拒绝

文件操作只在白名单目录内；执行命令、写文件逐次批准并留痕；屏幕能力默认关闭，操作必须由你的语音或点击触发。

知识库：从「面板里能搜」到「对话里真的用上」

目录级索引 + 分块 + BM25；再装一个 512 维本地向量模型，就升级成「关键词 + 语义」混合检索。

控制台 · 设置 · 知识库
  • 问「电脑很卡怎么办」也能命中写着「机器运行越来越慢」的那一段——靠语义，不是靠字面。
  • 索引建好就自动引用对话时把命中片段带给模型；弱相关块被门限挡掉，不往上下文里掺水。
  • 没装模型也照常用纯 BM25 关键词检索，功能不倒退；模型约 91 MB，应用内一键下载。
  • 全程不出本机索引、向量化、检索都在本地跑，文本一个字节都不外传。

技术架构

外壳与内核彻底分离：业务逻辑全在一个无 GUI 依赖的 Rust crate 里，换壳不用重写。

纯 Rust 核心

qibai-core 零 GUI 依赖，665 个测试不需要图形环境就能跑完（另 3 个 ignored；语音相关 7 条由 fetch_resources.sh 补齐本地语音包后即可跑通）；今天接 Tauri，明天接 CLI 或服务端，逻辑一行不用改。

一个状态源

对话、任务、演出、窗口状态都在 engine 里，前端只读投影；不会有「两边各记一份」的漂移。

默认最小出网

MCP 默认配置为空 → 不启动任何子进程；只有你显式触发的对话才把必要文本发给 LLM，Key 由你提供。

快速开始

仓库不含模型权重与美术帧（体积与许可双重原因），用脚本从上游官方 release 拉。

1

前置依赖

Rust 1.75+ 与 Git；Linux 另需 webkit2gtk 4.1 等系统库，macOS 装 Xcode 命令行工具，Windows 用 MSVC 工具链。

2

补齐大资源

模型、STT 二进制、五个角色的立绘与动作帧都不进仓库，两个脚本各管一边，幂等可重复跑。

# 模型与语音二进制
bash fetch_resources.sh
# 角色立绘与动作帧（3 个分卷 → md5 校验 → 拼接 → 解压）
bash fetch_personas.sh
3

跑测试 / 构建

# 核心库单测
cargo test -p qibai-core
# 构建
cd src-tauri && cargo build --release
# 打包安装包（需 cargo-tauri）
cargo tauri build
4

填 API Key

首次启动进控制台 → 设置页填写 LLM API Key（默认对接豆包 Ark，也可换任意 OpenAI 兼容接口）。Key 只落本地，不进日志。

隐私边界先说清楚：对话、设置、记忆、任务全部存放在本地数据目录，不同步、不上传；出网的只有你显式触发的那次对话请求； 文件读写限制在白名单目录内，越界直接拒绝；危险操作未确认则不执行，并留痕。
