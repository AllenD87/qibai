# 按钮清册与可用性口径（v45.24）

这份文档回答一个问题：**界面上每一个按钮，按下去到底会不会有反应。**

不是罗列设计稿，而是按当前源码核对出来的事实。核不出来的，我写在「还没做到的」里，不编。

---

## 一、盘子有多大（实测）

| 界面 | `<button>` 总数 | JS 里的 `click` 绑定 | 有 id 但 JS 完全找不到 |
|---|---|---|---|
| 控制台 `console.html` | 88 | 80+ 处 `addEventListener('click')` | **0** |
| 桌宠 `pet.html` | 24 | 28 处 | **0** |
| 合计 | **112** | 108+ 处（另有 `.onclick =` 若干） | **0** |

结论：**没有任何一个按钮是空壳**。此前审计脚本报「52 个按钮没接线」是误报——它只认 `getElementById('x')` 一种写法，而代码里混用了三种（`addEventListener` / `.onclick =` / `$('#id')`）。按任意写法重查，悬空数为 0。

无 id 的 24 个按钮（控制台）全部靠容器事件委托或 `data-*` 驱动，功能正常；`tests/test_all_buttons.js` 会打上 `data-spark-seq` 稳定标记后逐个点击判定，所以「无法被单独治理」这条已经不成立了。

## 二、v45.24 补齐的入口（本轮）

前几轮的口径是「按钮都点得动」，本轮往前推了一步：**后端有命令、但界面上够不着的，全部接上**。

| 后端命令 | 原来 | 现在 |
|---|---|---|
| `kb_search` | 能加目录、能建索引，唯独不能试搜 | 知识库区新增搜索框，回车/点按钮即检索，命中显示得分·文件·标题路径·片段；无命中时明确提示"先确认已索引" |
| `audio_diagnose` | 只有"测试输出设备"（会出声） | 新增「只看环境（不发声）」：读后端与 pacat/pw-play/paplay/rodio 工具链，排障时不会突然被扬声器吼一下 |
| `scan_plugin_library` | 只能一个个走"安装插件"选文件 | 插件页新增目录路径输入 + 「扫描目录」，一次登记整目录 |
| `skill_read_doc` | 技能卡片只有一行 description | 卡片新增「查看文档」，只读弹层展示 SKILL.md 正文 |
| `plugin_uninstall` | 点一下就 `remove_dir_all`，没有二次确认 | 走通用确认弹层，写明会删哪个目录、权限一并失效、不可恢复 |

另外补了 HTTP 连接器的诚实告知：后端 `transport != "stdio"` 一律强制 `enabled=false`（HTTP 传输至今是占位）。以前能填能存、界面上完全看不出为什么永远不工作；现在选中 HTTP 就显示黄条说明，点保存先确认"这是占位"，落库时直接按停用写入。

## 三、v45.22 完成的四件事（保留记录）

### 1. 三种状态以前长得一模一样

全表（`styles.css` 1097 行）此前**没有任何 `:active` 通用规则**，`:disabled` 也只覆盖了猜拳、保险箱等四处。后果：禁用的按钮和能点的按钮视觉完全一致，用户点了没动静只能怀疑卡了。

新增基础层（`styles.css`）：

```css
button:not(:disabled):active { filter: brightness(.9); }   /* 按下变暗 */
button:disabled { cursor: not-allowed; opacity: .5; filter: saturate(.55); }  /* 禁用发灰 */
button[data-busy="1"] { cursor: progress; opacity: .6; pointer-events: none; } /* 忙态 */
button:focus-visible { outline: 2px solid var(--rose); }   /* 键盘可达 */
```

只用 `filter` 给按下反馈、不动 `transform`，避免和各处 `:hover` 的位移打架。

### 2. 会重复出事的按钮，连点会被拦住并告知

点数、复制、打开弹窗这类幂等操作不拦（拦了反而吞掉正常点击）。**只拦真正有副作用的 30 个**：保存、建索引、下载模型、检查更新、发起匹配、装技能包、任务启停、清空记忆。

被拦住时明确说一句「别连点，上一次还在处理」，而不是静默吞掉。

实测证据（playwright 跑真实页面）：`btnSave` 在 200ms 内点两次，**后端只收到 1 次 `save_settings_partial`**。

### 3. 错误不再只进 devtools

以前 `console.js` 有 9 处、`pet.js` 11 处 `catch (e) {}`——失败被吞得干干净净，用户看到的等价于「按了没反应」。

现在：

- `console.js` **完全静默的 catch 归零**；
- `pet.js` 只剩 4 处，全部是 `debug_log` 自身（它本身就是日志，失败再报错会自我递归）；
- 两个界面都加了 `unhandledrejection` / `error` 兜底，转成 toast：「有个操作没成功：…」。

实测证据：手动造一个未处理的 Promise 拒绝，控制台弹出「有个操作没成功：模拟后端断连」，桌宠弹出「有个操作没成功：桌宠后端断连」。

### 4. 语音说「锁定了」但其实没锁——这类假成功修掉了

桌宠的语音指令里，三处是「后端失败照样回成功文案」：

| 指令 | 以前 | 现在 |
|---|---|---|
| 锁定位置 | 失败也回「好，位置锁死啦」，用户一拖发现还能拖 | 失败回「锁定没成功，后端没接住，位置现在还能拖。要不再试一次？」 |
| 解锁 | 失败也回「好，解锁啦」 | 「解锁没成功，后端还是锁着的。要不再说一次『解锁』？」 |
| 打开屏幕面板 | 失败也回「屏幕面板打开啦」 | 「屏幕面板没能打开，后端拒绝了这次请求。」 |

这是最典型的「做了却没用」——界面在撒谎。现在界面状态跟着后端走。

## 五、还没做到的（诚实边界）

1. **没有在真机里逐个点过 112 个按钮。** 本机缺 webkit2gtk 编不了 Tauri 壳，UI 层只能靠 chromium 加载 `file://` 页面 + mock 后端来验。上面所有「实测证据」都是这个方式拿到的，真机行为可能有差别（尤其是需要系统权限的：麦克风、屏幕读取、透明窗口）。
2. **112 个按钮的完整语义没逐条重写。** 只对 36 个有副作用／易误用的做了说明和防护，其余保持原样——它们本来就有可见文字，加了反而噪音。
3. **防连点现在是「2.5 秒窗口 + disabled 双保险」，仍不是事务级锁。** 真正的事务锁得由业务在 Promise 里持（点了就把按钮置 disabled 直到结束），目前只有部分按钮这么做了。
4. **HTTP 连接器没有实现，只是把话说明白了。** 要真做需要改 MCP 传输层（stdio → streamable HTTP），属于独立一轮的活。
5. **停止不杀 MCP 子进程**，与 v45.21 一致：界面收回了，后台那轮会跑完，产物保留。
6. **`.qbpk` 解包依赖的 `zip` 已从 2.6.1 升到 9.5.1**（GHSA-m665-v7pm-7grj critical 的补丁线是 9.0.5）。升级带来一处 API 变更（`entry.name()` 改为返回 `Result`），已修并补了"条目名不可读即拒收"的分支；但 `src-tauri` 在本机编不了，它的包仍需在具备 webkit2gtk 的机器上跑一次 `cargo build` 才算真验过。
