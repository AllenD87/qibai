# 动效设计：从"能画"到"好看"

代码只解决"怎么画"，这份文档解决"画成什么样、什么时候动、动多久"。

## 1. 先定结构，再定像素

按秒切段落，每段只承担一个信息任务：

| 时长 | 结构 | 说明 |
|---|---|---|
| 5s | 钩子 0–1.5 / 主体 1.5–4 / 落款 4–5 | 只能讲一件事 |
| 10s | 开场 0–2 / 主信息 2–6 / 证据 6–8 / 尾卡 8–10 | 演示片标准结构 |
| 15s | 开场 0–2.5 / 三层信息 2.5–11 / 尾卡 11–15 | 每层 2.5–3s |
| 30s | 4–5 段，每段 5–7s，段间用一次强转场 | 必须有章节感 |

硬约束：
- 开场 2 秒内必须出现"可读信息"，不能只是氛围。
- 每 2–3 秒换一次视觉层，否则注意力掉。
- 结尾留 0.6–1.2s 静止让观众读完落款；中途不要有超过 0.4s 的完全静止。
- 全片只允许 1–2 次"强转场"（马赛克、擦除、整体位移）；其余用淡入淡出与位移衔接。

## 2. 缓动选择表

选缓动看"这个元素在物理世界里应该怎么停"。

| 意图 | 缓动 | 时长 | 备注 |
|---|---|---|---|
| 元素入场（有重量） | `spring(stiffness 150–170, damping 12–15)` | 0.5–0.9s | 有一次轻微过冲后稳定 |
| 元素入场（轻、精确） | `outExpo` / `outQuint` | 0.3–0.5s | 无过冲，适合 UI、线条 |
| 元素出场 | `inQuad` / `inCubic` | 0.2–0.3s | 出场永远比入场快 |
| 位移、推镜 | `inOutCubic` / `inOutQuart` | 0.6–1.2s | 两头慢中间快 |
| 线条/进度展开 | `outQuint` + `spring` 收尾 | 0.6–0.8s | 展开后回弹 6–14px 才有"弹性" |
| 数字滚动 | `outExpo` | 0.6–0.9s | 末段减速，读得清 |
| 循环呼吸 | `sin(t * ω)`，ω = 1.6–2.6 | 全程 | 幅度 4%–8%，超过就像故障 |
| 强调（抖动/脉冲） | `outElastic` 或 sin 衰减 | 0.3–0.5s | 一屏最多一次 |
| 遮罩、转场 | `inOutSine` | 1.2–1.8s | 慢，才不刺眼 |

**不要全片只用一种缓动。** 一条片子里至少出现三种运动性格：弹（spring）、滑（outExpo/Cubic）、匀速漂移（sin）。

## 3. spring 参数速查

`AC.spring(t, start, { stiffness, damping, mass, velocity, from, to })` — 解析解，确定性。

| 观感 | stiffness | damping | 过冲 |
|---|---|---|---|
| 硬朗、快速稳定 | 200 | 20 | 几乎无 |
| 标准入场 | 160 | 14 | 轻微 |
| 果冻、可爱 | 140 | 10 | 明显（品牌片可用，数据片慎用） |
| 缓慢沉降 | 90 | 16 | 无，慢 |
| 甩入（带初速） | 150 | 12 + `velocity: 40` | 强 |

落地挤压：`sq = 1 + 0.12 * max(0, 1 - abs(p-1)*6) * sin((t-d)*14)`，然后 `scale(1/sq, sq)`。**只在 p 接近 1 时生效**，否则整段都在抖。

## 4. 时间参数（按元素尺寸给）

| 元素 | 入场时长 | 出场时长 |  stagger |
|---|---|---|---|
| 主标题（≥100px） | 0.7–0.9s | 0.25s | 0.05–0.06s/字，从中心散开 |
| 副标题（28–40px） | 0.4–0.5s | 0.2s | 不拆字 |
| 卡片 / 面板 | 0.35–0.5s | 0.2s | 0.04s/个 |
| 小图标、圆点 | 0.3–0.4s | 0.15s | 0.03s/个 |
| 分隔线 | 0.6–0.8s | 0.2s | 无 |

原则：**越大越慢，越远越慢**。大元素配短时长会显得"啪"地砸出来。

## 5. 十二条原则的代码化

| 原则 | 代码做法 |
|---|---|
| 预备（anticipation） | 入场前先反向偏移 8–16px（`y + 16 * (1-p)`），0.1s 就够 |
| 挤压拉伸（squash & stretch） | 落地瞬间 `scale(1/sq, sq)`，sq 峰值 1.1–1.15 |
| 跟随（follow-through） | 主元素停稳后，附属元素再晚 0.06–0.12s 停 |
| 次级动作 | 背景缓慢漂移、光斑呼吸——不能静止，也不能抢戏 |
| 层次（staging） | 同一时刻只有一处高对比；其余降饱和/降透明度 |
| 交叠（overlap） | 下一段入场压在上一段出场尾部 0.15–0.3s |
| 慢入慢出 | 除"强调"外不要 linear |
| 弧线（arcs） | 位移用二次贝塞尔，不要纯直线 |
| 夸张 | 位移距离取"刚好够"的 1.2 倍，不要 2 倍 |
| 时间控制 | 关键动作 0.3–0.8s；超过 1.2s 必须有中间变化 |
| 实体感 | 阴影、圆角、边缘光，别用纯色平涂的裸矩形 |
| 吸引力 | 一个记忆点（一个红点、一次扫光、一个跳动的数字） |

## 6. 版式与层级（1920×1080）

- 安全区：四周 6%（≈115 / 65px）。所有文字必须在里面。
- 字号阶梯：主标题 96–140 / 副标题 34–44 / 正文 28–36 / 注释 20–26。**小于 28px 在 1080p 投屏上读不清**。
- 主标题字重 700，正文 400–500；中文不要用斜体。
- 行宽不超过 22 个汉字；副标题一行，超过就删字。
- 留白：主体四周至少留 1 个字号高度的空。
- 对比度：背景是浅色时文字用 `#1d1a18` 这类近黑，不要用灰；浅色文字压在浅色块上必须加白/深色承托卡（圆角 + 阴影）。
- 颜色：1 个主色 + 1 个强调色 + 中性底色。强调色面积不超过画面 15%。

竖版 1080×1920：主标题 76–96px，正文 32–40px，安全区上下各 12%（预留平台 UI）。

## 7. 配方

### 逐字标题

```js
const d = 1.2 + AC.stagger(i, n, 0.055, 'center');
const p = AC.spring(t, d, { stiffness: 150, damping: 14 });
const y = baseY - 90 * (1 - p);
scene.text(ch, x, y, { size, weight: 700, align: 'center', color: '#1d1a18', group: 'title' });
```

### 数字滚动（配白卡承托）

```js
const p = AC.tween(t, 6.05, 0.85, 'outExpo');
const v = Math.round(AC.lerp(0, 300, p));
scene.text(`${v}`, cx, 560, { size: 96, weight: 800, align: 'center', color: '#1d1a18', group: 'stat' });
```

### 柱状图 / 条形图

```js
bars.forEach((v, i) => {
  const p = AC.spring(t, 0.6 + i * 0.07, { stiffness: 150, damping: 13 });
  const h = maxH * v * Math.max(0, p);
  if (p <= 0.001) return;                       // 不要留 0 高度残条
  ctx.fillRect(x, baseY - h, bw, h);
});
```

### 转场（马赛克 / 擦除）

用"从中心扩散"的网格，避免第一块出现在边角像脏点：

```js
const d = (Math.abs(r - rows/2) + Math.abs(c - cols/2)) * 0.042;
const s = Math.min(AC.tween(t, 5.42 + d, 0.34, 'outQuart'),
                   1 - AC.tween(t, 6.92 + d, 0.32, 'inQuart'));
```

转场开始时刻要比上一段的出场**早 0.1–0.2s**，不要让画面先空再进。

### 尾卡扫光

```js
const sh = AC.tween(t, 7.95, 1.7, 'inOutSine');
const x = AC.lerp(W * 0.95, -W * 0.25, sh);
const g = ctx.createLinearGradient(x, 0, x + 320, 0);
g.addColorStop(0, 'rgba(255,255,255,0)');
g.addColorStop(.5, 'rgba(255,255,255,.34)');
g.addColorStop(1, 'rgba(255,255,255,0)');
```

扫光只做一次，别循环——循环会变成"加载中"。

### 背景不能死

背景色相/位置做 8–12% 幅度的慢漂移（`inOutSine` 走完全片），或加 6% 透明度颗粒。完全静止的背景会让整片显得像截图。

## 8. 常见"廉价感"来源

- 所有元素同一时间、同一缓动入场 → 像 PPT 动画。
- 元素贴边、贴角，没有安全区。
- 字号阶梯断档（只有巨大标题和小注释，缺中间层）。
- 纯黑背景 + 纯白文字 + 无质感 → 像终端截图。
- 强调色面积过大、饱和度过高 → 廉价电商风。
- 转场硬切、结尾突然黑屏。
- 同一屏出现 3 个以上"会动的东西"，观众不知道该看哪。
