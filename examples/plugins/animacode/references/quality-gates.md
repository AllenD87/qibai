# 质量门禁与缺陷排查

`qa_report.py` 是唯一裁判。退出码 0 = 通过（允许告警），1 = 失败。门禁分两层：**帧级像素** + **场景审计**。

## 判定表

| 检查 | 依据 | 阈值 | 级别 |
|---|---|---|---|
| 帧数 | `round(fps*duration)` | 不等即报 | FAIL |
| 空帧 | alpha>8 的像素占比 | <1% | FAIL |
| 文字重叠 | 场景审计 `text-overlap` | 不同组交叠 >4px，且两者 alpha≥0.55 | FAIL |
| 出安全区 | 场景审计 `safe-area` | 6% 边距 | FAIL（记为告警汇总） |
| 小字号 | 场景审计 `tiny-type` | <28px×短边/1080（1080p 即 28px） | WARN |
| 低对比 | 文字盒外环取样 | 见下 | FAIL(<1.5:1) / WARN |
| 长静止 | 变化像素占比 + 局部峰值 | 占比 <0.25% 且峰值 <2.5，持续 >0.45s | WARN |
| 单帧突变 | 帧间差中位数 | >`max(12×中位, 12)` | WARN |
| 出框触边 | alpha 包围盒贴边 | >15% 帧贴边 | WARN |
| 亮度/饱和度 | 抽样帧 | `luma<40` 占比、平均饱和 | INFO |
| 视觉回归 | 16×16 灰度哈希 | 与基线不一致 | WARN（`--fail-on-change` 提级 FAIL） |

## 对比度怎么算才不误报

1. **只在稳定态取样**：`alpha<0.9` 的文字跳过——淡入半透明时它本来就该低对比。
2. **环形取样**：取文字盒向外扩 10% padding 的环，排除盒内文字像素污染背景中位数。
3. **真实底色**：区域中位色 + 文字色算 WCAG 对比度。
4. **按字号分档**（越大越可放宽）：≥48px → 3.0:1；≥28px → 3.8:1；更小 → 4.5:1。低于分档记 WARN，低于 1.5:1 记 FAIL。

v2 早期版本把淡入文字当低对比，报了一堆假阳性；加上 `alpha<0.9` 与环取样后归零。

## 分辨率与转场：两个已修的误报

- **小字号阈值随短边缩放**：28px 是 1080p 基准，720p/540p 预览按比例折算（`28×min(W,H)/1080`，下限 14）。否则 720p 场景每个 kicker 都被判 tiny。
- **重叠只判稳定可见**：转场交叠期一侧 alpha 很低，人人都会误报。现在要求两个文字盒 `alpha≥0.55` 才计重叠；同组（`group` 相同）本来就不判。

## 数值边界与降采样

- 降采样宽度默认按帧数自动算（`--work-w 0`），帧数越多自动越小；不同宽度下 `changed` 占比会差零点几个百分点，判“长静止”时看数量级，不要卡在阈值边缘。
- 对比度偶尔出现 `3.75:1 / need 3.8:1` 这种擦边告警：阈值按字号分档（28px 档 3.8）。差 0.05 时优先**把字号提一档或改深一档颜色**，比调阈值划算——投屏上 3.75 和 3.8 没区别，但告警列表里会一直挂着。

## 静止不是缺陷

`static 14.20-14.80s (0.60s)` 这类告警在尾卡是**有意停留**：片子需要一个落脚点。判它是不是缺陷看三件事——是否在结尾、是否有微动（呼吸/颗粒）、是否被下一镜头接走。三者成立就保留，并在交付说明里写一句。

真正该修的静止是**中段卡住**：镜头切进来了却一动不动，通常是缓动写错或条件分支把绘制 return 掉了。

## 视觉回归

```bash
# 第一次：写基线
python3 qa_report.py --frames frames --fingerprint fp.json --out qa.json
# 之后：比对
python3 qa_report.py --frames frames --baseline fp.json --out qa.json [--fail-on-change]
```

指纹是每帧 16×16 灰度哈希，改版式会大面积变化——**先确认变化符合预期，再覆盖基线**。用于改造既有片子时回答"我只想改这一处，别的地方有没有被带歪"。

## 排查顺序（渲染结果不对时）

1. 打开 `audit.json` 看 `issues` 类型，定位是布局还是可见性
2. 回到 100% 帧（不是接触表缩略图）确认元素真的在/不在
3. 若是"东西变暗/消失"，先查 `globalAlpha` 是否被连续 `*=` 连乘
4. 若是"被裁掉/比例不对"，查视口与 `mount:false`
5. 若是"文字糊在一起"，查 `group` 是否漏传
6. 修完必须重跑同一条命令，确认该指标归零，再继续下一项
