安装技能

内置技能

技能总开关
关闭后所有本地技能均不可用
内置技能受信任、权限已默认授予；执行命令属危险操作，每次执行前仍会逐次确认。

插件技能

外部插件安装后默认停用，需逐项授权权限后开启。

连接器（MCP / HTTP）

连接器把外部 MCP stdio 服务器或 HTTP 端点接入技能链：添加后自动注册进 LLM 工具表， 权限自动授予（MCP→command:run / HTTP→network:read），调用仍走危险命令逐次审批。
添加即自动授权并启用；移除会删除物化目录与配置。

技能包（.qbpk）

技能包是把插件技能打包分发的 zip 文件：导入后安全校验并安装，可再导出分享。

专家

专家接管对话人设与技能白名单；同一时间仅启用一位，停用即恢复默认人设。

代码检查（只读 · 本地隐私优先）

检查全程只读：不写文件、不上传代码；浏览器演示模式按关键词返回冻结形状报告。
