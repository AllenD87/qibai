# 塔罗占卜（tarot）

> 版本：1.0.0 ｜ 适配腾讯 WorkBuddy 技能规范 ｜ 来源参考与安全自查见包内 README.md

## Trigger

当用户提到占卜、塔罗、抽牌、算一卦、看看运势时触发。典型说法：

- 「用塔罗帮我抽三张牌，问问换工作的事」
- 「抽张牌，算一卦」
- 「今天的运势，塔罗看看」

## Instructions

1. 调用函数 `draw_tarot`，参数 `question` 传用户的问题或心情（可为空）。
2. 脚本在本地完成抽牌与解读（确定性随机：时间戳 + 问题文本为种子），按原文播报三张牌的牌名、正逆位与解读，最后念综合提示。
3. **播报纪律**：语气温和轻松；不追加脚本以外的预测话术；禁说「一定会」「千万要」「大凶」这类绝对化/恐吓措辞；用户提到生病、财务损失、官司等重大事项时，明确建议咨询医生/会计/律师等专业人士。
4. 一个问题只抽一次；用户要求「再抽一次直到抽到好牌」时，温和说明「牌面不负责翻到满意为止」。
5. 输出末尾的娱乐免责声明必须原样保留，不可省略。

## Example

用户：抽张牌，算算换工作的事

调用：`draw_tarot(question="换工作")`

回复（示意）：过去：隐士（正位）——适合独处复盘……；现在：星星（逆位）……；未来：太阳（正位）……。综合提示：……（末尾原样念出娱乐免责声明）
