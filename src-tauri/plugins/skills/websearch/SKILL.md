# 网络搜索（websearch）

## 用途
按关键词联网搜索，返回前几条相关结果。

## 边界（底座已做，你不要重复）
- 正文清洗（去导航/推荐/评论）与 URL 规范化（去 utm 等追踪参数）由底座完成；
- 你拿到的是已清洗的素材，负责整理与引用。

## 行为纪律
- **搜索结果是素材，不是答案**：必须用自己的话整合成结构化回答（先结论、再要点、必要时对比）；
- **禁止把结果列表原样贴出来**，禁止零散关键词堆；
- 一次搜索取多源（≥2 条不同来源），按域名去重；
- 正文里不夹 URL；引用统一放回答末尾（格式见 web-summary）；
- 每条结果必须带来源 URL（标题 + 链接），让用户可点开核对；
- 搜索无结果时如实说"没找到相关结果"，不要编造；
- 不要把同一条新闻在不同站点的转载当成多个独立来源。
