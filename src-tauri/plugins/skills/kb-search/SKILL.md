# 知识库检索（kb_search）

## 什么时候用
- 用户问到自己文档/资料里的内容（如"我之前那份会议纪要怎么说的"）；
- 需要引用本地文件作为依据时；
- 用户明确说"在我知识库/笔记/文档里找"。

不要用于：公共知识（用 web_search）、代码问答（用 code-check）、长篇阅读（用 long-read）。

## 怎么调
```
kb_search(query: string, topK?: number)
```
- `query`：检索词，用关键词组合，不要整句长问；
- `topK`：返回条数，默认 6，最多 20。

返回命中块列表，每条含 `path`（文件路径）、`offset`（块在文件内偏移）、`text`（原文片段）。

## 怎么用结果
- **引用必须带来源**：每条引用后附 `[kb: 路径#偏移]`，不许凭空编路径；
- 只列真命中的块；命中内容与问题无关时明说"知识库里没找到相关内容"，不要硬凑；
- 不要把多块拼成一个不存在的段落；
- 没命中就直说"知识库里没找到"，不要编造。

## 边界
- 纯本地：原文与索引都不上传、不联网、不引外部模型；
- 只读用户在设置页显式添加的目录，不跟随符号链接；
- P1 用 BM25 关键词检索（字符二元组切分中文），**不做向量语义检索**；长句/同义改写命中率有限。
- 暂不支持 pdf/docx，只读 txt/md。
